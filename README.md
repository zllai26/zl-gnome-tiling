<h1>What is zl-gnome-tiling/simple-gnome-tiling?</h1><p></p>
It is a lightweight, mostly script-driven WM for GNOME. This is the most simplest way to make GNOME a WM as removing GNOME stuff to turn back into pure Mutter is a lot of work to do.

<h2>Why download us?</h2>
<p></p>
You can try out a TWM is like on GNOME (most popular DE) and have a script to change wallpaper.

<h2>Keybinds</h2>
<p></p>
-Alt+Super = Go to a workspace (from 1 to 10 (0))
<br>
-Super+Ctrl+Alt = drag focused window to a workspace (from 1 to 10 (0))
<br>

-Ctrl+Alt+Num = change wallpaper to the one you set (inside wallpaper.py)
<br>

-Alt+F4/Ctrl+Q = close a window
<br>

-Shift+Enter = opens a terminal (beta mode)
<br>
